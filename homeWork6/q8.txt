align-items
Purpose: Aligns grid items along the block (vertical) axis within their grid area.
Affects: All grid items (children) inside the grid container.
Example values: start, end, center, stretch (default).

.grid-container {
  display: grid;
  align-items: center;
}


justify-items
Purpose: Aligns grid items along the inline (horizontal) axis within their grid area.
Affects: All grid items (children) inside the grid container.
Example values: start, end, center, stretch (default).

.grid-container {
  display: grid;
  justify-items: end;
}


align-content
Purpose: Aligns the entire grid (all rows as a group) along the block (vertical) axis within the grid container, when there is extra space.
Affects: The grid tracks (rows) as a whole, not individual items.
Example values: start, end, center, stretch (default), space-between, space-around, space-evenly.

.grid-container {
  display: grid;
  align-content: space-between;
}


justify-content
Purpose: Aligns the entire grid (all columns as a group) along the inline (horizontal) axis within the grid container, when there is extra space.
Affects: The grid tracks (columns) as a whole, not individual items.
Example values: start, end, center, stretch (default), space-between, space-around, space-evenly.

.grid-container {
  display: grid;
  justify-content: center;
}
